## これは何か

DeepSeek Harness 上で動く識別アシスタントで、次の2点に特化しています：

- **仮面ライダーのベルト**：DX か CSM か？ KO 品か？
- **バンダイのガンプラ**：EG / HG / RG / MG / PG / MB / 解体匠機のどれか？ 海賊版か？

設計上守る線は一本だけ：**「レビューを書く」工程を除き、一切大規模モデルを呼びません。** 撮影チェックリスト、識別、DX/CSM 判定、ナレッジ検索、情報源の格付け、偽情報のフィルタリングはすべて本機で完結し、トークン消費はゼロです。識別結果はローカルキャッシュに入るため、同じ写真群を再識別しても計算し直しません。

> 本プラグインは公式ツールではありません。識別は参考情報であり、詳細は[免責事項](#免責事項)をご覧ください。

## できること

### 必須の撮影要件（ここが核心であり、ヒントではありません）

プラグインは根拠が不足した識別リクエストを**ブロック**します。不正確な回答を返すことはしません：

| カテゴリ | 必ず撮影するもの | 箱がない／条件が整わない場合 |
|---|---|---|
| **ベルト** | バックルを**単体で外して**表裏を撮影（裏面に銘板が必要）、変身アイテムも**単体で外して**撮影 | ベルト全体、電池ボックス、変身音を追加 |
| **ガンプラ** | **パッケージ前面**（バンダイの商標とグレードの色帯を含む） | 多角度 + 特徴部分 + 購入記録 → それでも不可なら**型番を手動入力** |
| その他 | ブランド、型番、銘板の接写 | 多角度 |

リマインダーは仕様どおり3か所に表示されます：**起動ガイドでは大きな文字**、**撮影画面では常設バナー**（失敗時だけではなく常時）、**識別失敗時にもう一度**。

### DX / CSM の判別ロジック

**材質 → 体積 → ディテール → 音声を確認**の順に採点し、各段階に明確な判断基準があります：

- **材質**：金属ダイキャスト部品、皮革ライニング → CSM 側
- **体積**：DX より一回り大きく、厚い → CSM 側
- **ディテール**：レーザー刻印、個別シリアル、金属銘板 → CSM 側；射出成形の商標と年号 → DX 側
- **音声**：セリフ/BGM あり → 基本的に DX ではない；変身音と必殺音のみ → DX 側

2項目のスコアが接近した場合は**推測しません**：「疑わしい」を返して候補を列挙し、ユーザーに選ばせます。ユーザーの選択は**訂正ストア**に書き込まれ（最優先、以降の更新で上書きされません）。

### 偽情報と情報源の格付け

情報源の信頼度は**導出される**もので、ラベルを貼るものではありません：

```
公式サイト > X/YouTube 公式アカウント（VPN 必須）> 国内公式アカウント（青稲妻＋認証主体＋アイコン）
> 公式発売リスト > 当時の公式プロモ動画 > 大手EC/主要Wiki
> 当時の投稿・ブログ > 黄稲妻UP主 > 一般UP主 > グループチャット
```

**Bilibili アカウントの判定**：青稲妻 = 公式；黄稲妻 = 参考のみ；稲妻なし = 最低。
青稲妻**だけでは不十分**です——認証主体、カスタムアイコン、そしてタイトル**と**概要の両方が玩具・模型のテーマを示している必要があります。どれか一つでも欠ければ**ダイアログでユーザーに確認**し、その結果はユーザーのホワイトリストに書き込まれ、次回以降は確認しません。

**登録基準**：少なくとも**2つの独立した情報源**が一致し、かつ少なくとも1つが登録可能な情報源であること。満たさない場合は「未確認」と表示します。**AI 生成コンテンツは表示のみで、登録しません。**

**検索エンジン**：中国語は Bing を優先；Baidu の入口は任意で、表示時は必ず「未認証」と表示；海外は Google、ロシア語は Yandex；**360 / 搜狗 / 2345 は使用しません**。

### リッチモード（任意で有効化）

既定では大衆向けモデルのみを対象とします。有効化すると以下も含みます：

- **ガンプラ**：PG / MGEX / MB / 解体匠機 / RE100 / FULL MECHANICS / HI-RESOLUTION / 限定 / 海外非バンダイ / GK
- **ベルト**：CSM / CS / 食玩 / ガシャポン / 限定 / マイナーな付属品

### 多言語

完全対応：**簡体字中国語 / 繁体字中国語 / 英語 / 日本語**。
UI 翻訳：韓国語、フランス語、スペイン語、ポルトガル語、ロシア語、広東語、ベトナム語、ドイツ語、イタリア語、オランダ語、ポーランド語。
すべての言語のフォールバックは英語で、キーが欠けても生のキーが露出することはありません。

## インストール

### 方法1：リポジトリのリンクをそのまま DSH に送る

```
このプラグインをインストールしてください：https://github.com/dsh-community/dsh-plugin-tokusatsu-gunpla
```

### 方法2：コマンドラインから特定の profile に入れる

```bash
dsh plugin --profile <あなたのprofile> add @dsh-plugin/tokusatsu-gunpla
```

その後、その profile の `cordis.patch.yml` に1行追加します：

```yaml
- name: '@dsh-plugin/tokusatsu-gunpla'
  config:
    richMode: false
```

### 方法3：ローカル開発（公開しなくても使える）

```bash
git clone https://github.com/dsh-community/dsh-plugin-tokusatsu-gunpla
cd dsh-plugin-tokusatsu-gunpla

# profile の node_modules 内にシンボリックリンクを作成（Windows は junction）
# そのうえで上記の方法2の cordis.patch.yml の行を追加
```

詳細は [docs/INSTALL.md](docs/INSTALL.md) を参照してください。

## 設定

すべて profile の `cordis.patch.yml` で変更します：

| フィールド | 既定値 | 説明 |
|---|---|---|
| `richMode` | `false` | リッチモード |
| `visionEnabled` | `true` | ローカル視覚エンドポイントを使うか |
| `visionBaseUrl` | `''` | OpenAI 互換エンドポイント；空なら `127.0.0.1:11434 / :1234 / :8080` を自動検出 |
| `visionModel` | `''` | モデル名；空ならエンドポイントが最初に報告したもの |
| `visionTimeoutMs` | `120000` | ローカル推論のタイムアウト |
| `visionMaxImages` | `6` | 1回の識別での画像上限 |
| `cacheTtlMs` | `86400000` | 識別キャッシュの保持時間、0 で無効 |
| `searchLanguage` | `'zh'` | 検索マーケットの言語 |
| `allowBaidu` | `false` | Baidu の入口を併記するか（常に「未認証」と表示） |
| `showCompliance` | `false` | GDPR / EU AI Act の説明を表示するか |
| `requireAcknowledgement` | `true` | 先に免責事項への同意を必須にするか |

### 「ローカル小型モデルによる識別」について

プラグインはあなたの写真をクラウドに**送信しません**。**本機ですでに動作している** OpenAI 互換の視覚エンドポイントを呼び出します：

```bash
# 例：Ollama
ollama pull qwen2.5-vl
ollama serve        # 127.0.0.1:11434 をリッスン
```

エンドポイントが使えない場合もエラーにせず、外部へも発信しません——自動的に**撮影チェックリスト + 型番の手動入力**の経路へ縮退し、やはりトークン消費はゼロです。

## 4つのローカルツール

プラグインを導入すると、アシスタントはこの4つのツールを使えます。いずれも**すべてローカルで実行**されます：

| ツール | 役割 |
|---|---|
| `gear_identify` | 識別 + 海賊版判定 + 版の判定 + 信頼度；結果はキャッシュに入り UI に公開 |
| `gear_checklist` | 撮影チェックリストの生成・照合、不足分の算出 |
| `gear_decide_edition` | DX / CSM の採点と追加質問チェーン |
| `gear_knowledge` | ナレッジ検索、検索計画、情報源の採点、クロスチェック、訂正ストアへの書き込み、ローカルストアへの書き込み |

ツールの戻り値には結論と根拠チェーンがすでに含まれているため、アシスタントが型番を推測し直す**必要はありません**——これもトークン節約の要です。

## インターフェース

3つの UI 面があり、いずれも Harness の slot システムで登録します：

1. **起動ガイド**（会話入力エリアの上）：大きな文字の撮影要件 + 免責事項のチェック + コンプライアンス説明 + リッチモードのスイッチ。**同意にチェックしない限り撮影画面は現れません。**
2. **撮影ガイド**（常設）：カテゴリ切り替え、常設のリマインダーバナー、チェック可能な撮影チェックリスト、不足分のリアルタイム表示。
3. **結果パネル + 設定ページ**：結果カードには信頼度と根拠が付き、「疑わしい」場合は選択して訂正できます。設定ページでは言語、リッチモード、Baidu の入口、ローカルエンドポイント、免責事項、コンプライアンス説明を管理します。

## 開発

```bash
node scripts/smoke.mjs         # 69 項目：撮影チェックリスト、判断ツリー、海賊版判定、情報源の格付け、エンドツーエンド
node scripts/client-test.mjs   # 43 項目：クライアント契約、4言語のレンダリング、slot 登録、i18n フォールバック
```

どちらのテストもネットワークもモデルも不要です。

```
lib/
  index.js      プラグインの入口、設定 schema、session projection（結果を UI へ）
  tools.js      モデルから見える4つのツール
  identify.js   識別のメインフロー（根拠 → 海賊版ゲート → 照合 → 判定 → 信頼度）
  checklist.js  撮影要件エンジン
  decide.js     DX/CSM 判断ツリー
  sources.js    情報源の格付け、Bilibili 判定、クロスチェック、検索エンジンのルーティング
  vision.js     ローカル視覚エンドポイントのクライアント + 縮退
  store.js      3層ナレッジベース（内蔵 seed / 検証済み / ユーザー訂正）
  i18n.js       言語カタログ、免責事項、コンプライアンス説明
  client.js     ブラウザ側（起動ガイド / 撮影ガイド / 結果パネル / 設定ページ）
data/
  seed-catalog.json       内蔵エントリと判断基準
  official-whitelist.json 公式認証主体のホワイトリスト
```

ローカルデータディレクトリ：`$DSH_HOME/plugin-data/tokusatsu-gunpla/`。これを削除することが削除権の行使になります。

1. **識別は参考情報です**：本プラグインは非公式ツールであり、結果が誤っている可能性があります。
2. **非公式**：バンダイ、東映、円谷プロ、その他いかなるメーカーとも関係なく、許諾も受けておりません。
3. **データは公開情報に基づきます**：公開資料の整理であり、古い情報や誤りを含む場合があります。公式情報を優先してください。
4. **QQ 連携にはアカウント停止リスクがあります**：有効化する場合、リスクは利用者の負担となります。
5. **AI コンテンツは購入助言ではありません**：レビューや説明は AI 生成の可能性があり、投資・購入の推奨ではありません。
6. **オープンソース・現状有姿**：明示黙示を問わずいかなる保証もありません。自己責任でご利用ください。
7. **国内・KO・海外サードパーティを推奨しません**：模倣品の検出は警告であり、推奨ではありません。

### GDPR / EU AI Act（EU のユーザー向け）

- **GDPR**：識別データは既定で本機にのみ保存されます（`$DSH_HOME/plugin-data/tokusatsu-gunpla`）。プラグインは写真もナレッジベースもアップロードしません。ローカルデータディレクトリを削除すれば削除権を行使できます。プラグインはユーザープロファイリングを行いません。
- **EU AI Act**：本プラグインはオープンソースかつ非ハイリスク用途の AI システムであり、補助的な識別と情報整理のみを行います。AI 生成コンテンツはすべて情報源の階層を明示し、表示のみで登録はしません。
- **透明性**：結果には信頼度と根拠チェーンが付随し、ユーザーの訂正は自動結果より優先されます。

### つまずき回避メモ

- QQ グループの作成には実名認証が必要

- ロシア語は Yandex / VK / RuTube を使う
